# Hunodan paired photograph/template corpus

All 27 images linked by <https://www.hunodan.dk/julehjerter/julehjerter.html>, retrieved on 2026-09-07. `sources.json` records their URLs and SHA-256 hashes; `source/index.html` preserves the source listing. The source page credits `http://permo.homepage.dk/` for the patterns. Artwork rights remain with their original creators; no software licence is assigned to these images.

These are regression-test inputs requested by the user, kept outside the public site's assets. Each source image includes the photograph and its published cutting template. Photograph regions supply reconstruction inputs; template regions are held separately for validation. A template is evidence of the intended geometry, rather than proof of physical cutting tolerances or assembly strength.

The two flag designs include different templates for the two sheets. Some other templates have cuts ending inside the paper; the current full-length-slit model must not label those references impossible merely because opposite-border endpoint counts differ.

The user excluded patterns with interior slit endpoints from the required score. See `scope.json`: all 27 sources remain available, with 24 regular designs required.
