- Artifact downloaded through the GitHub connector, then extracted without changing the WASM or wrapper files.
- No npm registry request, remote script CDN, or external solver service is made when running the app.

The browser port uses the persistent sparse-model interface in this precise wrapper. Do not replace only the WASM file, silently switch to a floating CDN release, or assume a different wrapper has the same API. Choose a dependency update deliberately, update both files and notices, and rerun the numerical and browser tests before public deployment.
